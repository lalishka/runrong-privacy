RUNRONG — foreground service demo

Recorded on a Samsung Galaxy A55 (Android). The user starts a guided walk/run session; the workout keeps running in a foreground service with an ongoing notification after the user leaves the app.

  • location: GPS records the route, distance and pace only during an active run/walk session the user started (permission "While using the app").
  • mediaPlayback: offline voice coaching cues (stage changes, countdowns) play during the session, also when the screen is off or another app is open.
  • specialUse: the workout interval timer keeps counting for the whole session and is shown in the ongoing notification; the service stops when the session ends.
